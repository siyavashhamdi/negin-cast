# NeginCast — صفحه فرود ویدیو

صفحه فرود زیبا و حرفه‌ای با React + Vite برای تماشا و دانلود ویدیو — مخصوص دختران. رابط کاربری فارسی با پشتیبانی کامل RTL و فونت BYekan.

## شروع سریع

```bash
npm install
npm run dev
```

مرورگر را روی [http://localhost:5173](http://localhost:5173) باز کنید.

## اسکریپت‌ها

| دستور | توضیح |
| ----- | ----- |
| `npm run dev` | اجرای سرور توسعه |
| `npm run build` | ساخت نسخه production |
| `npm run preview` | پیش‌نمایش نسخه production |

## فونت

فونت `BYekan` در مسیر `public/fonts/byekan.ttf` قرار دارد.

## تکنولوژی

- React 19
- Vite 6
- CSS خالص (بدون فریم‌ورک UI)
